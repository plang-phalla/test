# Workshop Check-In Mobile App

A simple React Native (Expo) app to manage workshop attendee check-ins. It collects attendee details, tags the workshop area, and shows a running list of recent check-ins.

## Features
- Quick check-in form with name, email, workshop area, and notes.
- Recent check-in list with timestamps.
- Mobile-friendly layout and styling.

## Getting Started

```bash
npm install
npm run start
```

Then scan the QR code with Expo Go on a mobile device or launch an emulator.
